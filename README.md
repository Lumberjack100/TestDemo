# mCloudapp_V5 项目文档

欢迎查阅 mCloudapp_V5 项目文档！本目录包含了项目的详细技术文档，旨在帮助您快速了解项目、上手开发和理解架构设计。

## 📚 文档目录

### 1. [项目梳理文档](./docs/项目梳理文档.md)
全面介绍项目的基本信息、功能特性、技术栈和模块划分。适合初次接触项目的开发者快速了解项目全貌。

**主要内容：**
- 项目概述和定位
- 技术架构总览
- 各模块功能说明
- 支持的设备类型
- 开发规范和配置要求

### 2. [架构设计说明](./docs/架构设计说明.md)
深入剖析项目的架构设计理念和实现细节，并包含真实的代码示例，帮助开发者深入理解项目的技术架构。

**主要内容：**
- 分层与MVVM架构设计
- Koin依赖注入实现
- 通信架构（蓝牙、网络、TCP）
- 数据存储方案（Room、MMKV）
- UI基类体系

### 3. [快速上手指南](./docs/快速上手指南.md)
为新加入的开发者提供快速上手指导，包含环境配置、开发示例和常见问题解决。

**主要内容：**
- 开发环境准备与项目运行
- 核心功能（页面、ViewModel）开发示例
- 常用工具类（日志、Toast、权限）使用
- 调试技巧和代码规范

## 💡 使用建议

1. **新人入职**：建议按照以下顺序阅读
   - `快速上手指南.md` → `项目梳理文档.md` → `架构设计说明.md`

2. **功能开发**：根据具体需求查阅相关章节
   - 开发新页面：参考 `快速上手指南.md` 中的示例。
   - 理解整体架构：阅读 `项目梳理文档.md`。
   - 深入技术细节：查阅 `架构设计说明.md`。

3. **问题排查**：
   - 查看 `快速上手指南.md` 中的"常见问题排查"。
   - 查看 `架构设计说明.md` 中的"异常处理机制"。
