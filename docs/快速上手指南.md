# mCloudapp_V5 快速上手指南

## 环境准备

### 1. 开发工具
- **Android Studio**: Hedgehog | 2023.1.1 或更高版本
- **JDK**: 17 或更高版本
- **Git**: 用于版本控制

### 2. 环境配置
```bash
# 克隆项目
git clone [项目地址]

# 使用Android Studio打开项目
# File -> Open -> 选择项目根目录下的 build.gradle.kts
```

### 3. 依赖同步
打开项目后，Android Studio会自动基于`gradle/libs.versions.toml`下载并同步所有依赖。

## 项目结构快速了解

```
mCloudapp_V5/
├── app/                    # 主应用模块（UI和业务逻辑）
├── core_commonlib/         # 通用工具库
├── core_data/              # 数据层（Repository、数据源）
├── core_model/             # 数据模型定义
├── lib_ble/                # 蓝牙功能模块
├── lib_cmd/                # 设备指令模块
├── lib_network/            # 网络请求模块
└── lib_tcp/                # TCP通信模块
```

## 运行项目

### 1. 选择构建变体
在Android Studio的 `Build Variants` 窗口中，选择 `debug` 构建变体。

### 2. 运行应用
- 连接Android设备或启动模拟器
- 点击 "Run 'app'" 按钮或使用快捷键 `Shift+F10`

## 调试技巧

### 1. 日志查看
- 使用Logcat并过滤 `tag:OkHttp` 查看网络请求日志。
- `MCloudApplication.kt` 中初始化了 `Timber`，可直接使用。

### 2. 调试工具
- **Layout Inspector**: 查看和调试视图层级。
- **Database Inspector**: 查看Room数据库中的内容。
- **Network Inspector**: 监控和分析网络请求。

### 3. 常见问题排查
- **编译失败**: 检查`libs.versions.toml`中的依赖版本是否正确，清理并重新构建项目。
- **蓝牙连接失败**: 确认`AndroidManifest.xml`中蓝牙权限是否完整，并检查运行时权限申请逻辑。
- **网络请求401/403**: 检查`NetDataRepository`中为请求添加的`Authorization`请求头是否正确、Token是否过期。

## 代码规范

### 1. 命名规范
- **类名**: 大驼峰 `DeviceListActivity`
- **函数名**: 小驼峰 `loadDeviceList()`
- **常量**: 全大写下划线 `MAX_RETRY_COUNT`
- **布局文件**: 全小写下划线 `fragment_device_list.xml`

### 2. 代码风格
- **基类使用**: 所有Activity/Fragment必须继承自项目定义的`Base`类。
- **协程使用**: 在`viewModelScope`或`lifecycleScope`中启动协程。
- **资源引用**: 优先使用`R.string`, `R.color`等，避免硬编码。
