# ML101/MS101 设备主页面需求记录

## 具体实现需求

请你按照给你的原型图页面，实现 ML101/MS101 主页面，页面为 `/app/src/main/java/com/shmedo/mcloudapp/ui/page/device/collector_product/fragment/ml101/ML101HomeFragment.kt`。可以参考 MG301 设备的主页面 `MG301HomeFragment.kt` ，注意：

 1. ML101(ProductType.C_L_1)、MS101(ProductType.C_S_2) 都包含 '设备信息'、'快捷配置'、'高级配置'分组。
 1.1 对于 ML101(ProductType.C_L_1) 的 '设备信息' 分组卡片中包含 '基本信息'、'电台信息'、'状态信息'、'位置信息'。
 1.2 对于 MS101(ProductType.C_S_2) 的 '设备信息' 分组卡片中包含 '基本信息'、'卫通信息'、'状态信息'、'位置信息'。
 1.3  对于 ML101(ProductType.C_L_1) 的 '高级配置' 分组卡片中包含 '电台配置'、'RS485配置'、'RS232配置'、'时间校准'、'系统配置'。
 1.4  对于 MS101(ProductType.C_S_2) 的 '高级配置' 分组卡片中包含 '卫通配置'、'RS485配置'、'RS232配置'、'时间校准'、'系统配置'。

 2. 添加导航配置 ml101_graph.xml，在导航配置 ml101_graph.xml 中添加 fragment、action 节点配置，更新 ML101HomeFragment 导航配置
 
 3. 添加详细的注释说明
