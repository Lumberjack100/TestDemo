# MS101 卫通配置页面需求记录

## 具体实现需求

请你按照给你的原型图页面，实现 MS101 卫通配置页面，页面为 `MS101SatConfigFragment.kt`。请参考`M50RadioSettingFragment.kt` 实现，注意：

1. "卫星联网状态上报" 为单选，可选项为 "关闭"、"开启"、"开启并上报数据帧号"。

2. "卫星休眠模式" 为单选，可选项为 "不休眠"、"定时休眠"、"自动休眠"。

3. 关于 "待发数据"，当选择 "指定删除" 时，自动显示删除数据帧号的输入框，选择 "不删除" 或者 "全部删除" 时，不需要显示删除数据帧号的输入框。

4. IOTCommandType.kt 中：
    - 使用 IOTCommandType.MD_CFG_SAT_PARAM 指令。

5. 扩展并使用 `MS101SatParamInfo.kt` 实体类，在 `com.shmedo.lib.cmd.base.iot_cmd.assemble.entity.ml101` 包中新建相应的实体类
 
6. 在导航配置 ml101_graph.xml 中添加 fragment、action 节点配置，更新 ML101HomeFragment 导航配置，关联新的基本信息页面并移除旧的占位配置。

7. 添加详细的注释说明

##  相关指令说明

### **卫通参数涉及的指令**
```  
（1）获取参数
发送：
$cmd=md_cfgsatparam&method=0

应答：
$cmd=md_cfgsatparam&method=0&status=1&sn=0001836&cesq=-10&csq=-66&waitnum=240&cregmode=0&cpsmmode=0&cpsmlevel=9&svmdmode=0&cclrmode=0

（2）设置参数	
发送：
$cmd=md_cfgsatparam&method=1&cregmode=0&cpsmmode=0&cpsmlevel=9&svmdmode=0&cclrmode=0

应答：
设置成功：$cmd=md_cfgsatparam&method=1&result=succ
设置失败：$cmd=md_cfgsatparam&method=1&result=fail&reason=
```

####  指令参数字段说明

| 关键字 | 说明 | 数据类型 | 示例 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| method | 功能码 | int | 1 | 0-查询 <br> 1-设置 |
| status | 接入状态 | int | 1 | 0-未接入 <br> 1-已接入 |
| sn | 产品序列号 | string | 0001836 | |
| cesq | 卫星信号质量 | string | 一般 | (1) 差：小于-10（不含-10）；<br>(2) 一般：-10~-6；<br>(3) 较好：-5~0；<br>(4) 好：大于 0（不含 0）；<br>(5) 无：等于-128； |
| csq | 环境噪声信号强度 | string | -67 | |
| waitnum | 待发数据数量 | int | 240 | 值 0-480 |
| cregmode | 卫星模组联网状态上报 | int | 0 | 0：关闭联网状态上报 <br> 1：开启联网状态上报<br> 2：开启联网数据上报，并在数据发送成功后上报数据帧编号；<br>默认 0 |
| cpsmmode | 卫星模组休眠模式 | int | 0 | 0：不休眠<br>1：定时休眠<br>2：自动，有待发数据是定时休眠，无待发数据时一直休眠；<br>默认 0 |
| cpsmlevel | 卫星模组休眠模式等级 | int | 9 | 休眠等级，取值范围 1-9，<br>cpsmmode=0 时，无效。默认 9 |
| svmdmode | 用户数据存储区满时处置方式（数据存储溢出处理） | int | 0 | 0：停止接收：存储满后不再接收新数据<br>1：循环覆盖：存储器满后，覆盖最早的数据<br>默认 0 |
| cclrmode | 删除存储区待发数据 | int | 0 | -1：全部删除；<br>0：不删除；<br>1～m：指定删除，删除第 m 帧待发数据，m 取值 1～480。 |
