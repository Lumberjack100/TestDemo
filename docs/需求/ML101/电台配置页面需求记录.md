# 电台配置页面需求记录

## 具体实现需求

请你按照给你的原型图页面，实现 ML101 电台配置页面，页面为 `ML101RadioConfigFragment.kt`。请参考`M50RadioSettingFragment.kt` 实现，注意：

1. 根据工作模式选择中心节点还是终端节点，如果选择中心节点，目标地址（target_addr）自动配置为0，如果选择终端节点，按照手动输入的值配置。

2. IOTCommandType.kt 中：
    - 使用 IOTCommandType.M50_MD_RADIO_PARA 指令。

3. 使用 `M50RadioParam.kt` 、 `M50RadioParamEntity.kt` 实体类
 
4. 在导航配置 ml101_graph.xml 中添加 fragment、action 节点配置，更新 ML101HomeFragment 导航配置，关联新的基本信息页面并移除旧的占位配置。

5. 添加详细的注释说明

##  相关指令说明

### **串口参数涉及的指令**

```  
（1）获取参数
发送：
$cmd=md_cfgradioparam&method=0

应答：
$cmd=md_cfgradioparam&method=0&sw=1&mode=3&baud=6&freq_group=0&airbaud=2&encrypt_mode=0&qos=0&ttl=0&wakesingle=0&txpower=20&local_addr=1&target_addr=2&send_mode=0&encrypt_key=

（2）设置参数	
发送：
$cmd=md_cfgradioparam&method=1&sw=1&mode=3&baud=6&freq_group=0&airbaud=2&encrypt_mode=0&qos=0&ttl=0&wakesingle=0&txpower=20&local_addr=1&target_addr=2&send_mode=0&encrypt_key=

应答：
设置成功：$cmd=md_cfgradioparam&method=1&result=succ
设置失败：$cmd=md_cfgradioparam&method=1&result=fail&reason=
```

####  指令参数字段说明

| 字段 | 字段说明 | 数据类型 | 示例 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| method | 获取或设置模式配置 | Int | 1 （默认） | 0： 获取当前参数信息；<br> 1： 设置参数； |
| sw | 工作开关 | int | 1 | 0： 关闭， 1： 开启， 默认开启 |
| mode | 工作模式 | int | 2 | 工作模式 0~3： （TypeA~TypeD） ； 默认 3 |
| baud | 串口波特率 | Int | 6 | 0~7：<br>("2400","4800","9600","19200","38400","57600","115200","230400"） ；<br>默认 115200 |
| freq_group | 频点组号 | Int | 0 | 0~19 (470.41, 472.41, ..., 508.41MHz)<br>默认 470.41 |
| airbaud | 空中速率 | Int | 2 | （1： 2.4kbps； 2： 19.2kbps （默认） ； 3： 76.8kbps）<br>默认 2 |
| encrypt_mode | 加密模式 | Int | 0 | 0： 不加密 （默认） ； 1： 启用加密 <br> 默认不加密 |
| qos | 重传等级 | Int | 0 | 0~3 （对应重传次数） （默认 0） （等级越高，<br>抗干扰性越强， 不过时延越大）<br>默认 0 |
| ttl | 最大转发次数 | Int | 0 | （0~15） （默认 0） |
| wakesingle | 发送唤醒信号标志 | Int | 0 | 0： 不发送； 1： 发送 （TypeC 需要发送）<br>默认发送 |
| txpower | 发射功率 | Int | 20 | （0~20）<br>默认 |
| local_addr | 本地节点地址 | int | 1 | 1 - 65535 |
| target_addr | 目标节点地址 | int | 2 | 0 - 65535(仅目标地址可设置为 0，此时表示广播功能，所有同频设备均可收到) |
| encrypt_key | 模组密钥 | string | “1234567890123456” | 长度 32 位 |
