# ML101 RS232 配置页面需求记录

## 具体实现需求

请你按照给你的原型图页面，实现 ML101 RS232 配置页面，页面为 `ML101RS232ConfigFragment.kt`。参考 `ML101RS485ConfigFragment.kt` 实现，注意：

1. "开关" 项使用 com.kyleduo.switchbutton.SwitchButton 实现

2. IOTCommandType.kt 中：
    - 使用 MD_CFG_EXT_SERIAL_PARAM 指令。
 
3. 在导航配置 ml101_graph.xml 中添加 fragment、action 节点配置，更新 ML101HomeFragment 导航配置，关联新的基本信息页面并移除旧的占位配置。

4. 添加详细的注释说明

##  相关指令说明

### **参数涉及的指令**
```  
（1）获取参数
发送：
$cmd=md_cfgextserialparam&method=0

应答：
$cmd=md_cfgextserialparam&method=0&rs485_sw=1&rs485_mode=2&rs485_baud=9600&rs485_paritybit=N&rs485_dataBit=8&rs485_stopbit=1&rs232_sw=1&rs232_mode=2&rs232_baud=115200&rs232_paritybit=N&rs232_dataBit=8&rs232_stopbit=1

（2）设置参数	
发送：
$cmd=md_cfgextserialparam&method=1&rs232_sw=1&rs232_mode=2&rs232_baud=115200&rs232_paritybit=N&rs232_dataBit=8&rs232_stopbit=1

应答：
设置成功：$cmd=md_cfgextserialparam&method=1&result=succ
设置失败：$cmd=md_cfgextserialparam&method=1&result=fail&reason=
```

####  指令参数字段说明

| 字段 | 字段说明 | 数据类型 | 示例 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| method | 功能选择 | int | 1 | 0：查询<br>1：设置 |
| rs232_sw | 232 开关 | int | 1 | 0：关<br>1：开 |
| rs232_mode | 232 功能模式 | int | 2 | 0：关闭输出<br>1：日志输出<br>2：数据透传 |
| rs232_baud | 232 波特率 | int | 115200 | 9600<br>57600<br>115200<br>默认 115200 |
| rs232_paritybit | 232 校验位 | string | N | N：none<br>O：odd<br>E：even<br>M：mark<br>S：space<br>默认 N |
| rs232_dataBit | 232 数据位 | int | 8 | 取值 5-8，默认 8 |
| rs232_stopbit | 232 停止位 | string | 1 | 1、1.5、2，默认 1 |
