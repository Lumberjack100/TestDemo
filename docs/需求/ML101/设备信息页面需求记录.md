##  相关指令说明

### **卫通信息涉及的指令**
```  
发送：
$cmd=md_cfgsatparam&method=0

应答：
$cmd=md_cfgsatparam&method=0&status=1&sn=0001836&cesq=-10&csq=-66&waitnum=240&cregmode=0&cpsmmode=0&cpsmlevel=9&svmdmode=0&cclrmode=0
```

####  指令参数字段说明

| 关键字 | 说明 | 数据类型 | 示例 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| method | 功能码 | int | 1 | 0-查询 <br>1-设置 |
| status | 接入状态 | int | 1 | 0-已接入 <br>1-未接入 |
| sn | 产品序列号 | string | 0001836 | |
| cesq | 卫星信号质量 | string | 一般 | (1) 差：小于-10（不含-10）；<br>(2) 一般：-10~-6；<br>(3) 较好：-5~0；<br>(4) 好：大于 0（不含 0）；<br>(5) 无：等于-128； |
| csq | 环境噪声信号强度 | string | -67 | |
| waitnum | 待发数据数量 | int | 240 | 值 0-480 |
