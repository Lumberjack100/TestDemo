 ##  相关指令说明

 ### **移动网络参数涉及的指令**

 ```  
（1）获取参数
发送：
$cmd=md_getnet4guse

应答：
$cmd=md_getnet4guse&use=1

（2）设置参数	
发送：
$cmd=md_setnet4guse&use=1

应答：
设置成功：$cmd=md_setnet4guse&result=succ
设置失败：$cmd=md_setnet4guse&result=fail&reason=
```

注：use=1表示开启4G功能，use=0表示关闭4G功能

### **以太网参数涉及的指令**

 ```  
（1）获取参数
发送：
$cmd=md_geteth0

应答：
$cmd=md_geteth0&dhcp=0&ip=172.168.5.241&gateway=172.168.5.254&dns=8.8.8.8

（2）设置参数	
发送：
$cmd=md_seteth0&dhcp=0&ip=172.168.5.241&gateway=172.168.5.254&dns=8.8.8.8

应答：
设置成功：$cmd=md_seteth0&result=succ
设置失败：$cmd=md_seteth0&result=fail&reason=
```

####  指令参数字段说明

| 关键字 | 说明 | 数据类型 | 示例 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| dhcp | IP 分配 | int | 0 | 手动：0 （只能选手动）<br>自动：1 （不支持） |
| ip | IP 地址 | string | 172.168.5.242 | |
| gateway | 网关 | string | 172.168.5.254 | |
| dns | 域名系统 | string | 8.8.8.8 | |
