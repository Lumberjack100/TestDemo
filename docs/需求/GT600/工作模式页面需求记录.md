##  相关指令说明

### **工作模式涉及的指令**

```  
（1）获取参数
发送：
$cmd=md_getbaseposition

应答：
$cmd=md_getbaseposition&mode=1&lat=0.000000&lon=0.000000&alt=0.000000

（2）设置参数	
发送：
cmd=md_setbaseposition&mode=1&lat=0.000000&lon=0.000000&alt=0.000000

应答：
设置成功：$cmd=md_setbaseposition&result=succ
设置失败：$cmd=md_setbaseposition&result=fail&reason=
```

####  指令参数字段说明
| 关键字 | 说明 | 数据类型 | 示例 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| mode | 工作模式 | int | 0 | 0 表示自动模式；<br>1 表示手动模式； |
| lat | 纬度 | float | | |
| lon | 经度 | float | | |
| alt | 高程 | float | | |

##  相关指令说明

### **参数涉及的指令**

```  
（1）获取参数
发送：
$cmd=md_gnssmode&method=0

$cmd=md_gnssmode&method=0&station=1

（2）设置参数	
发送：
$cmd=md_gnssmode&method=1&station=0

应答：
设置成功：$cmd=md_gnssmode&method=1&result=succ
```

####  指令参数字段说明

| 关键字 | 说明 | 数据类型 | 示例 | 备注 |

| station | 站点类型 | int | 1 | 0: 基站<br>1: 测站 |
