##  相关指令说明

### **串口参数涉及的指令**

```  
（1）获取参数
发送：
$cmd=md_getdbguart

应答：
$cmd=md_getdbguart&type=1&baud=9600

（2）设置参数	
发送：
cmd=md_setdbguart&type=1&baud=115200

应答：
设置成功：$cmd=md_setdbguart&result=succ
设置失败：$cmd=md_setdbguart&result=fail&reason=
```

####  指令参数字段说明

| 关键字 | 说明 | 数据类型 | 示例 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| type | 功能码 | int | 1 | 1: 传感器采集<br>2: NMEA 输出<br>3: 差分数据输入<br>4: 差分数据输出<br>5: 原始数据输出<br>6: 解算结果输出 |
| baud | 波特率 | int | 9600 | 9600<br>19200<br>38400<br>57600<br>115200 |

##  相关指令说明

### **功能开关参数涉及的指令**

```  
（1）获取参数
发送：
$cmd=md_sensor&method=0

应答：
$cmd=md_sensor&method=0&switch=1

（2）设置参数	
发送：
$cmd=md_sensor&method=1&switch=0

应答：
设置成功：$cmd=md_sensor&result=succ
设置失败：$cmd=md_sensor&result=fail&reason=
```

####  指令参数字段说明

| 关键字 | 说明 | 数据类型 | 示例 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| method | 功能选择 | int | 1 | 查询参数：0 <br>设置参数：1 |
| switch | 功能开关 | int | 1 | 0: 关<br>1: 开 |
