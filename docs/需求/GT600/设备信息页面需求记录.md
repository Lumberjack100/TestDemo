# 网络信息页面需求

请你参考  `M50NetInfoFragment.kt` 、`UDNetInfoFragment.kt` ，实现 GT600 网络信息页面，页面为 `GT600NetInfoFragment.kt`。
1. 包含 '数据网络'、'数据链路'分组。
  1.1 '数据网络' 分组卡片中展示的字段如下：
    - '移动网路'，通过 ‘4g’ 字段展示，值为 'on' 表示已启用，值为 'off' 表示未启用。
    - '网络类型'，通过 'type' 字段展示，4G/2G。
    - '运营商'，通过 'isp' 字段展示，中国移动/中国电信/中国联通。
    - '信号强度'，通过 'csq' 字段展示，加上负号进行处理。
    - 'IMEI'，通过 'imei' 字段展示。
    - 'ICCID'，通过 'iccid' 字段展示。


  1.2 '数据链路' 分组卡片中展示的字段与 m20s 设备一致。
    - '数据中心 1'，通过 'socket1' 字段展示处理。
    - '数据中心 2'，通过 'socket2' 字段展示处理。
    - '数据中心 3'，通过 'socket3' 字段展示处理。
    - '数据中心 4'，通过 'socket4' 字段展示处理。

2. 在导航配置 gt600_graph.xml 中添加 fragment、action 节点配置，更新 GT600HomeFragment 导航配置，关联新的基本信息页面并移除旧的占位配置。
3. 添加详细的注释说明
