# 基本信息页面需求

请你参考 m20s 设备的基本信息页面 `M20SBaseInfoFragment.kt` 实现的功能，实现 GT600 基本信息页面，页面为 `GT600BaseInfoFragment.kt`。注意：
1. 包含 '设备信息'、'存储信息'分组。
  - '设备信息' 分组卡片中展示的字段与 m20s 设备一致。
  - '存储信息' 分组卡片中展示的字段与 m20s 设备一致。但是，GT600 的存储信息中，'空间' 字段的单位为 'GB'，而不是 'MB'。
2. 在导航配置 gt600_graph.xml 中添加 fragment、action 节点配置，在 `GT600HomeFragment` 中引用 action
3. 添加详细的注释说明
