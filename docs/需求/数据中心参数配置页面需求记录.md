# 数据中心参数配置页面需求记录

## 需求背景

请你优化 `UniversalDataCenterParamFragment.kt` 、`fragment_data_center_param.xml`，来适配 `NewDataCenterPlatform.kt` 中新增的 "云南地灾加密平台"。

1. "云南地灾加密平台" 对应的 dataProtocol 是 MQTT，在 `fragment_data_center_param.xml` 中：
  - 需要隐藏 "设备注册码" 输入项。
  - "设备注册地址" 文本改成 "加密服务地址"。
  - "设备注册端口" 文本改成 "加密服务端口"。
