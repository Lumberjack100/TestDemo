# 监测数据导出功能使用说明

## 概述

监测数据导出功能允许用户通过BLE连接从物联网设备获取监测数据，并将数据导出为Excel文件。

## 支持的设备类型

- MR702
- MR701  
- DAS

## 使用方法

### 1. 进入导出功能

1. 连接到支持的BLE设备
2. 在设备配置页面找到"系统配置"
3. 点击"监测数据导出"选项

### 2. 设置时间范围

1. 选择开始时间和结束时间
2. 时间范围不能超过7天
3. 确保设备在该时间范围内有数据

### 3. 开始传输

1. 点击"开始传输"按钮
2. 等待数据传输完成
3. 传输过程中会显示进度条

### 4. 导出Excel

1. 传输完成后，点击"导出Excel"按钮
2. 文件将保存到设备的Download目录
3. 文件名格式：监测数据_设备SN_时间戳.csv

## 注意事项

1. 确保设备已正确连接并有足够的电量
2. 传输过程中请保持蓝牙连接稳定
3. 大量数据传输可能需要较长时间
4. CSV文件可以用Excel直接打开

## 文件格式

导出的CSV文件包含以下字段：
- 设备序列号
- 时间戳  
- 传感器数据（JSON格式）
- 创建时间

## 错误处理

如果传输失败，请检查：
1. 蓝牙连接是否正常
2. 设备是否支持该功能
3. 时间范围是否合理
4. 设备存储空间是否充足
