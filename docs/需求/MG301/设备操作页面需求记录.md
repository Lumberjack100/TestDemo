# MG301 设备操作页面需求记录

## 具体实现需求

请你按照给你的原型图页面，实现 MG301 设备操作页面，页面为 `MG301DeviceOperationFragment.kt`，可以参考 `MR702EquipmentOperationFragment.kt` 实现。

 1. 目前只有 `卫星数据清空` 功能模块。
 
 2. IOTCommandType.kt 中：
    - 添加 md_cleansatdata 指令。

 3. 在导航配置 mg301_graph.xml 中添加 fragment、action 节点配置，更新 MG301DeviceOperationFragment 导航配置
 
 4. 添加详细的注释说明

##  相关指令说明

### **卫星数据清空涉及的指令**

```  	
发送：
$cmd=md_cleansatdata&number=0

应答：
设置成功：$cmd=md_cleansatdata&result=succ
设置失败：$cmd=md_cleansatdata&result=fail&reason=
```
