# 基本信息页面需求

请你按照给你的原型图页面，实现 MG301 基本信息页面，页面为 `MG301BaseInfoFragment.kt`。可以参考  `GT600StatusInfoFragment.kt`、`M20SStatusInfoFragment.kt` 等，注意：

1. 包含 '设备信息'、'存储信息'分组。

2. 使用 IOTCommandType.kt 中以下指令：
    - MD_GET_DEVICE_STATUS

3. 如果必要的话，可以在 `com.shmedo.lib.cmd.base.iot_cmd.model.mg301`  包中新建相应的实体类，在 `com.shmedo.lib.cmd.base.iot_cmd.parser` 包下创建` 包中新建对应的解析器类，以及在 IOTParserRegistry.kt 中注册。

5. 添加详细的注释说明
